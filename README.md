# PW01ТВ-31_Гогуля Максим Дмитрович

Практична робота №1 з дисципліни "Мобільні системні розробки" (MSE).

## Інформація про студента
- **ПІБ:** Гогуля Максим Дмитрович
- **Група:** ТВ-31
- **Проєкт:** MSE (Практична робота №1)

## Опис завдань
- **Task 1:** Прогноз та контроль рівня води ГЕС (`HydroForecastScreen`)
- **Task 2:** Калькулятор енергетичних показників ГЕС (`HydroConfigScreen`)
- **Task 3:** Дашборд моніторингу та аналітики ГЕС (`HydroDashboardScreen`)
- **Task 4:** Форма авторизації та реєстрації оператора ГЕС (`AuthRegistrationScreen`)

## Технологічний стек
- **Мова:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Архітектура:** Single Activity
